# NCM International for Android

An unofficial English client for NetEase Cloud Music (网易云音乐). Not made by or affiliated with NetEase.

This repository only publishes the app: each [release](https://github.com/nickEatsBread/ncm-releases/releases) has
the signed APK. There's no source here.

## Install

1. Download `ncm-international-<version>.apk` from the
   [latest release](https://github.com/nickEatsBread/ncm-releases/releases/latest).
2. Open it on your phone, and allow installs from your browser or file manager when Android asks.

Needs Android 8.0 or newer and a NetEase account.

## Updates

The app looks here for a newer release when it starts (and from Settings > Check for updates) and installs it
itself. When GitHub can't be reached it asks ncm.miaou.si, which mirrors the latest release.
